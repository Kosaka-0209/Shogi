# 将棋 Siv3D

将棋のルールやAIのアルゴリズムを一から実装しました。

## AIの実装

- Negamax法による指し手探索
- αβ枝刈りによる効率化
- それぞれの駒の点数に基づく評価
- 探索深さの設定

## ソースコード

- AI.cpp: AIの処理
- Board.cpp: 盤面管理
- Movement.cpp: 駒の移動処理-
- Check.cpp: 王手の判定
- Promotion.cpp: 駒の成処理
- Main.cpp: ゲームのメイン処理

## 制作で工夫したところ

AIの実装です。 単純に指せる手をランダムに指すのではなく、しっかり盤面を評価し、指し手を選択できるように実装しました。
また、探索深度を増やすと処理時間が長くなるため、αβ枝刈りを取り入れ、探索する必要のない候補を減らすことで、処理の効率化を実現させました。

## 制作で難しかったところ
将棋のルールの複雑さをどう実現させるかです。 具体的には、単に駒を移動させるだけでなく、移動させた場所が王手にはならないか、 二歩にはならないかなど、盤面全体を考慮する必要があったことです。

## 将棋制作を通して学んだこと
複雑な将棋のルールをどう実現させるか、試行錯誤しながら取り組んだこと。 
また、AIのアルゴリズムではただ最善手を求めるだけでなく、考慮時間をいかに少なく 効率よく探索できるかどうかを考えました。 
今後は盤面評価の改善や探索処理の最適化を行い、より強いAIの実現を目指しています。
